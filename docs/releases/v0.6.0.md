# Ygg v0.6.0

Released 2026-08-23.

## Highlights

- **Subagent overhaul** — extension-routed child sessions with raised limits
  (eight concurrent workers), opt-in `edit`/`write`/`bash` mutation grants,
  continue/resume across sessions, live worker telemetry while root tools run,
  a native `/subagents` browser, and styled subagent transcripts in the TUI.
- **First-party extension bundles ship for the first time** — checksum-verified,
  atomically installed, inert until enabled *and* trusted:
  `ygg-browse`, `ygg-web-search`, `ygg-mcp`, `ygg-subagents`, plus the
  version-matched loopback-only `ygg-serve`.
- **Deferred tool-schema loading** ported from Pi's deferred-tools design:
  tools registered mid-session are announced on the tool result and excluded
  from static request schemas by deferred-capable providers.
- **Tool wall-time telemetry**, bash-only duration rendering, and speculative
  recon execution.
- Responses WebSocket preferred where available; improved provider failure
  diagnostics.
- `ygg-web-search`: `web_open` renamed to `web_fetch` (extension v0.3.0).
- The `ygg-ssh` portal extension was removed from the catalog.

## Compatibility

- Extension bundles require executable-extension API 0.2 and Ygg = 0.6.0 for
  the version-matched Serve package.
- Prompt templates remain Pi-compatible; skills follow the Agent Skills spec.

## Installation

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/skaft-software/ygg/releases/download/v0.6.0/install-ygg.sh | sh
```

Requires macOS (Apple silicon or x86-64) or GNU/Linux x86-64, plus ripgrep.
