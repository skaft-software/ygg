# ygg v0.6.6

Release-candidate notes for the v0.6.6 daily-driver closure release. Public
GitHub, npm, and Homebrew publication and hosted acceptance remain external
release gates; this file does not claim that those gates have completed.

## Highlights

- Bound environment and credential reads, repaired tool arguments against their
  selected schemas, and retry transient remote reads with bounded backoff.
- Isolated Git clean filters, strengthened durable goal locking across
  processes, bounded web session resync and selection races, and reconciled TUI
  inline scrollback.
- Hardened GitHub descendant cleanup, Responses WebSocket half-open detection,
  max-turn completion semantics, and session-resume notices.
- Improved DeepSeek V4 discovery metadata and synchronized the embedded Serve
  web bundle.
- Added deterministic, no-lifecycle npm launcher/platform packages and an
  immutable-metadata Homebrew formula handoff. These channels fail closed for
  unsupported platforms and require their protected publication gates.

## Installation and updates

The canonical binary release will provide the version-pinned installer for
GNU/Linux x86-64, macOS Intel, and macOS Apple silicon:

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/skaft-software/ygg/releases/download/v0.6.6/install-ygg.sh | sh
```

Then restart Ygg and verify:

```sh
ygg --version
ygg --help
ygg doctor
```

Cargo users can install the immutable tag with Rust 1.86 or newer:

```sh
cargo install --locked \
  --git https://github.com/skaft-software/ygg \
  --tag v0.6.6 \
  --bins \
  ygg-coding-agent
```

The npm launcher and Homebrew formula are documented in
[`docs/distribution.md`](../distribution.md) and
[`docs/release/npm-trusted-publishing.md`](../release/npm-trusted-publishing.md).
They are available only after their corresponding verified external release
gates complete.

## Compatibility and known limits

- Core crates and first-party extension manifests target Ygg `0.6.6` exactly.
- Executable-extension API `0.2` remains the wire contract.
- Prebuilt targets remain GNU/Linux x86-64, macOS Intel, and macOS Apple
  silicon; Linux musl and unsupported CPUs are rejected.
- Existing configuration, credentials, sessions, goals, extensions, and Serve
  data remain in place across installer upgrades.
- Theme selection remains disabled; the compiled model-aware default is the
  only runtime theme.
- Local packaging checks do not establish registry publication, provenance,
  hosted macOS acceptance, or clean-host acceptance.
