## Work completed or substantially implemented

- Added a deterministic semantic action model with action/run/turn identity,
  semantic kinds, states, safe presentation metadata, duration and exit
  information, evidence links, and repeated-command aggregation.
- Added deterministic investigate/change/verify/produce grouping and replaced
  the generic fallback phase label with `Executing`.
- Kept raw arguments and unbounded command output behind host-owned resources;
  public data uses bounded presentation fields and opaque handles.
- Added a compact activity rail with one operation-level working indicator.
- Replaced animated sidebar activity with a static state marker, removed the
  composer perimeter and generic rail animation, and strengthened reduced-motion
  behavior.
- Added honest structured result parsing for Cargo, Vitest/Jest, Pytest, and Go
  tests. Unsupported output does not invent suite, case, or pass counts.

### P0: reviewable completion

- Added a dominant completion-review surface with outcome, duration, actions,
  changed files, verification, warnings/failures, outputs, and evidence
  coverage.
- Added changed-file hierarchy rendering and exact diff/snapshot resource
  opening.
- Added inspector split/unified diff modes and hunk navigation.
- Fixed the changed-file tree builder to retain all nested `changedPaths`
  instead of losing siblings while constructing the hierarchy.
- Added structured completion-review fixtures and focused component coverage.

### P0: rendering and store performance foundations

- Added batched/coalesced event publication, indexed item updates, and
  resource-to-action indexes.

  reparsing settled rows.

  provider request path with a deterministic local OpenAI-compatible provider.

  outstanding.
