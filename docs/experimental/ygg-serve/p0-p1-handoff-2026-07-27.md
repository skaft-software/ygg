## Work completed or substantially implemented

### P0: semantic activity and working-state hierarchy

- Added a deterministic semantic action model with action/run/turn identity,
  semantic kinds, states, safe presentation metadata, duration and exit
  information, evidence links, and repeated-command aggregation.
- Added deterministic investigate/change/verify/produce grouping and replaced
  the generic fallback phase label with `Executing`.
- Kept raw arguments and unbounded command output behind host-owned resources;
  public data uses bounded presentation fields and opaque handles.
- Added a compact activity rail with one operation-level working indicator.
- Replaced animated sidebar activity with a static state marker, removed the
  composer perimeter and generic rail animation, and strengthened reduced-motion
  behavior.
- Added honest structured result parsing for Cargo, Vitest/Jest, Pytest, and Go
  tests. Unsupported output does not invent suite, case, or pass counts.

### P0: reviewable completion

- Added a dominant completion-review surface with outcome, duration, actions,
  changed files, verification, warnings/failures, outputs, and evidence
  coverage.
- Added changed-file hierarchy rendering and exact diff/snapshot resource
  opening.
- Added inspector split/unified diff modes and hunk navigation.
- Fixed the changed-file tree builder to retain all nested `changedPaths`
  instead of losing siblings while constructing the hierarchy.
- Added structured completion-review fixtures and focused component coverage.

### P0: rendering and store performance foundations

- Added batched/coalesced event publication, indexed item updates, and
  resource-to-action indexes.
- Avoided rebuilding catalog summaries for transcript-only events.
- Memoized committed Markdown and prevented unrelated live deltas from
  reparsing settled rows.
- Added a coalesced scroll-follow scheduler and manual scroll-away preservation.
- Added long-transcript containment, including a settled assistant-message
  fallback, and opaque mobile inspector treatment.
- Added a 1,000-item/100-command performance fixture, three simultaneous
  working sessions, a replay-recovered session, long content, reload/
  rehydration coverage, manual scroll-away coverage, frame/long-task
  instrumentation, and Darwin visual snapshots.
- Fixed compressed filename/count spacing in the mobile completion review.

### P1: projects, trust, repository context, files, and documents

- Added a durable project registry with canonical roots, stable identifiers,
  create/import/update/archive/default behavior, trust persistence/revocation,
  and session binding.
- Added repository/worktree context projection for Git facts plus folder
  instructions, origins, precedence, and load errors.
- Added bounded MIME-sniffed ingest and storage for UTF-8 text, Markdown, and
  ordinary PDFs, with extraction provenance and hostile-input limits.
- Added trusted-root file catalog, search, read, and immutable prompt-context
  snapshots without accepting client-authored host paths.
- Added Projects, ProjectContext, and PromptContextPicker web surfaces.
- Fixed a production wiring defect where Conversation did not forward the
  document/project-file callbacks; an integration test now opens the picker
  and loads the catalog.

### P1: transcript search, drafts, and notifications

- Added persisted transcript search across supported visible content, snippets,
  filters, highlighting, and jump-to-item behavior, with backend and web tests.
- Added bounded per-host/per-session text and attachment draft persistence for
  submit, steer, and follow-up modes, including corrupt-storage handling.
- Added opt-in, transition-deduplicated browser notifications for completed,
  failed, and attention-required background sessions, with session deep links
  and graceful unsupported/denied behavior.

### P1: conversation branching, retry, fork, and lifecycle

Backend and protocol work:

- Added active/archive/trash lifecycle, 30-day retention metadata, restore, and

- Added actor retirement/quiescence before lifecycle mutations and pre-ack

- Extended host bootstrap/model/command/service/supervisor/transport contracts,

## Partial work and known gaps

### Immediate integration gaps

- Sidebar lifecycle props are optional and the Sidebar UI exists, but `App`
  does not yet pass the session-trash capability or lifecycle/permanent-delete
  callbacks. The store and transports have the methods; the visible production
  path still needs that final wiring.
- RuntimeStatus has Rust and web foundations, but no production backend
  snapshot route/adapter and no App/transport integration. It is not a shipped
  runtime surface yet.
- The patched bootstrap golden fixture has not been rerun.
- The mobile completion-review snapshot must be regenerated and visually
  inspected after the spacing fix.

### Conversation recovery limitations

- There is no end-to-end adapter test proving a successful real
  provider-backed edit/retry execution.
- Permanent deletion removes session JSONL, metadata, project binding, and the
  transcript-search projection, but not document, attachment, or
  resource-store sidecars.
- A fork copies the exact committed JSONL ancestor chain and project/provenance
  metadata, but does not clone attachment/resource associations. Historical
  auxiliary UI resources may therefore not fully rehydrate in the fork.
- No final Rust formatting, strict Clippy, or full coding-agent test pass was
  performed.

### Review-workflow gaps

- The changed-file/review model does not yet comprehensively aggregate
  deleted, renamed, binary, shell, and extension mutations.
- Large-file and binary review states remain incomplete.
- Authenticated full command-log handles and a complete persisted redacted
  command-history product are incomplete.
- Host-owned preview start/readiness/failure/restart/stop and reconnect
  lifecycle are not implemented end to end.
- Capability-gated host-mediated open-in-editor/terminal/browser actions are
  not complete.
- Git/pull-request status projection with explicit source and refresh state is
  not complete.

### Runtime and final-gate gaps

- MCP management, skills/extensions management, LSP lifecycle, runtime
  parentage, compaction reconciliation, and fine-grained policy presentation
  exist only as status-model/display foundations, not proven production
  integrations.
- The 60-delta path must be stabilized until repeated reference runs have no
  task over 50 ms.
- Final typecheck, lint, unit, production build, embedded-bundle, full fixture
  Playwright, and production-host Playwright gates were not run on the
  converged tree.
- Final Rust formatting, strict Clippy, exact-feature/full-workspace gates,
  installed-binary smoke, and package-boundary verification were not run on the
  converged tree.
- No real configured-provider acceptance matrix was run for fresh/restore,
  concurrency, tools, files/documents, steer/follow-up/stop, reconnect,
  branching, review, search, and restart.
- No commit-ready performance evidence document was added.
